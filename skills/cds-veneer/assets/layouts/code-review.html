Concern

Security

Reviewed
  • Auth surface: cookie lifetime tightened from 7d → 1d with 1h rotation. Sessions remain server-validated; no client-side token changes.
  • Input handling: no new public endpoints introduced.
  • Recommendation: verify the rotation grace window against any long-running background jobs that authenticate as the user.

Concern

Architecture

Reviewed
  • New boundary: a `ClinicCache` module sits between the lookup service and storage. Owns its own invalidation rules.
  • Coupling: the lookup service now depends on the cache module's interface. Backwards-compatible — no public signature changes.
  • Radiates: downstream consumers of `lookupClinic()` see no behavior change. Internal latency profile shifts (10x faster on cache hit).
